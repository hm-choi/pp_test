# Experiment 3 — DF versus InvDF results

Configuration: two-sided \(\alpha=0.05\). Each row uses a Chebyshev
interpolant of the stated degree. The maximum error and RMSE are measured
against SciPy's Student-t quantile on a dense linear-plus-logarithmic grid.

The domains are:

- InvDF universal: \(1/\mathrm{df}\in[0,1]\), evaluated over
  \(\mathrm{df}\in[1,2048]\).
- DF global: \(\mathrm{df}\in[1,2048]\).
- DF group-aware: the insurance group-size bound
  \(\mathrm{df}\in[273,1336]\).

Direct DF is unsuitable as a single low-degree polynomial over the wide
global interval because the t critical value changes sharply near
\(\mathrm{df}=1\). It becomes highly accurate when the domain is narrowed
using public group sizes. The trade-off is that its interval and coefficients
are group-size dependent, whereas one InvDF coefficient set covers all
positive degrees of freedom.

## Encrypted arithmetic

The HE table is generated by the remote HEaaN run and written to
`he_results.csv`. Run:

```bash
python3 experiments/experiment3/test.py
```

It compares, on identical insurance observations:

- parameter and t-statistic error;
- induced degree-15 critical-value error;
- arithmetic, critical-value, and total runtime;
- arithmetic, critical-value, and total bootstrap counts.
